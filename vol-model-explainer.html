个股波动率是怎样估出来的？

这页用一个真实的研究节点，逐步解释 Realized、Model Estimate 和 Market Context 分别是什么、如何连接，以及为什么它们不能被当成同一个波动率数字。

先给结论：Realized 是历史收益的 P 测度信息；Model Estimate 是用历史信息和模型得到的卖价等效 IV 预测；Market Context 是当天参考卖价反解出来的卖价等效 IV。当前模型的目标是：没有当天个股 Market Context 时，也能从历史信息独立生成一张可报价曲面；Market Context 只在校准和验证阶段提供参考标签。

三个来源先分清楚

REALIZED · P 测度

已经发生了什么

从复权收盘收益计算过去 5、20、60 个交易日的年化波动。它描述历史市场状态，用来构造模型特征和做情景参考。

不能直接叫 IV。它没有包含期权市场对未来风险、尾部和流动性的定价。

MODEL ESTIMATE

模型认为应当怎样报价

第一层先预测未来 realized volatility，再经过上市 ETF 的 P→Q 诊断桥；第二层学习参考卖价等效 IV 与基础预测之间的差额。

页面显示的是最终预测的 offer-equivalent IV，包含当前研究模型对卖方报价层的估计。

MARKET CONTEXT

参考报价实际怎样卖

把当天参考卖价放进和模型完全相同的 carry、现金分红、BUS/252 和 Black 现金结算核，反解出一个等效 IV。

它包含报价方的风险溢价、流动性储备和商业影响，不能被解释成纯粹的“市场中间 IV”。

1

历史行情

收益、成交额、涨跌停和市场状态 → Realized 与特征

2

第一层模型

LightGBM 预测未来 1–4M realized → base_iv

3

P → Q 桥与二层模型

上市 ETF 风险溢价 + Market Context 历史标签 → Model Estimate

4

定价

预测 IV、forward、贴现和结算条款 → Black 现金结算卖价

第一步：Realized 怎样进入模型

对每个股票和每个历史日期，只使用当日收盘前已经可见的数据。示例训练记录包含以下特征；它们不是“直接加权平均”，而是作为 LightGBM 的输入，让树模型学习非线性条件关系。

这里的未来 realized 标签只用于训练和时间外验证；模型在真实报价日运行时不能看到未来收益。

这是假设基础模型的波动率直接进入共同定价核后的价格。它还没有加入 Market Context 的报价层调整。

为什么不是直接用 RV20？

因为未来一个月的风险可能不同于过去一个月。模型同时看短、中期波动、趋势、流动性、涨跌停和市场状态，学习“在什么条件下，未来波动通常如何变化”。

例如 RV60 高于 RV20 时，模型可以把较长背景作为持续风险；RV5 突然上升时，也可以学习短期冲击是否会延续。

第三步：上市 ETF 怎样做 P → Q 诊断桥

Realized 和第一层模型属于历史测度 P；期权价格反映的是风险中性测度 Q。我们用上市 50ETF / 300ETF 期权曲面提供市场风险溢价的方向参考，但不把 ETF 的 IV 直接复制为个股 IV。

listed_risk_premium = listed_ATM_IV − listed_realized_RV base_iv_q = clip(base_iv + w × listed_risk_premium, 0.001, 3.0) 示例：31.18397% + 0.25 × (15.72239% − 22.11850%) = 31.18397% − 1.59903% = 29.58494%

本例中上市 ATM IV 低于 ETF RV，所以桥接把 base_iv 向下调整。

质量门控：本例是 green：曲面拟合正常、日历和蝶式检查无违规、年龄为 0 天、两只 ETF 都有覆盖。因此质量因子为 1.0。若是 amber，权重减半；若是 red，桥接调整置零。默认 w=0.25 仍是研究参数，不是生产锁定参数。

本例的 P→Q 桥价格为 2.79842% 本金，即 27,984.16 CNY。它在这个单点上比 base_iv 价格更低；这只是市场状态诊断，不能单独证明它比基础模型更准确。

第四步：Market Context 怎样变成训练标签

Market Context 给的是一个最终卖价，而不是一个直接提供的 IV。我们先在相同 carry 下反解，保证标签和模型输入使用同一套合同口径。

Market Context offer = 3.81% × 1,000,000 = 38,100 CNY 求 σ，使得： 3.81% = DFpayoff / DFpremium × Black(0.98588353, 1.00, 0.08730159, σ) 解得 σMC = 38.33715%
Market Context label
参考卖价比例3.81000%
反解 offer-equivalent IV38.33715%
反解回代误差≈ 0 bp

这个 IV 是“在当前 carry 下能产生该卖价的等效波动率”，不是拆分出来的纯市场中间 IV。

随后为每个股票、期限和 strike 构造二层标签：

delta_iv = iv_offer_from_same_carry − base_iv 本例：38.33715% − 31.18397% = +7.15318 vol pt 二层模型学习： features + tenor + strike + base_iv + base_iv_q + market-state features → predicted_delta_iv

delta_iv 不是纯商业利润。它混合了模型误差、个股风险溢价、流动性储备、carry 误差和参考报价方的商业加点。只有取得多方 bid/offer、中间价和费用拆分后，才有可能进一步识别其中的成分。

第五步：MODEL ESTIMATE 怎样得到

第一层：base_iv = 31.18397% P→Q 诊断：base_iv_q = 29.58494% 二层预测：predicted_delta_iv = +3.18171 vol pt 最终 MODEL ESTIMATE： predicted_offer_iv = base_iv + predicted_delta_iv = 31.18397% + 3.18171% = 34.36568%

页面中的 Model Estimate 采用预测的 offer-equivalent IV，因此它可以和 Market Context 直接比较“报价层级”；Realized 则不应该拿来和卖价直接做报价差额比较。

在 Demo 的曲面表里，Realized layer 对同一期限的不同 strike 暂时展平；这是历史参考层，不是预测的 smile，也不是风险中性曲面。

一个数据版本提示：训练 CSV 中该点的 RV20 特征为 18.01171%，而公开页面的 compact realized layer 显示 17.55565%。这是两个已保存数据工件的计算窗口／版本差异，不是模型把 Realized 直接改成了 IV。生产版本需要统一同一份 point-in-time 复权历史和窗口定义。

因此页面上三层的正确阅读方式是：

  • Realized：回答“最近实际发生了多大波动？”
  • Model Estimate：回答“在没有当天个股参考卖价时，模型估计应该用什么卖价等效 IV？”
  • Market Context：回答“参考报价方当天的卖价，在同一合同核下相当于多少 IV？”

三者怎样相互作用，怎样不相互作用

来源进入模型的位置最终是否需要它不能做什么
REALIZED生成 RV/EWMA/趋势等 P 测度特征；生成未来 realized 标签做训练和 OOS 验证；作为页面情景层。独立运行需要历史行情；不需要当天个股报价。不能直接充当 risk-neutral IV 或最终卖价。
MODEL ESTIMATE第一层预测 base_iv；P→Q 桥提供诊断；二层预测 delta_iv；再回代为最终价格。这是没有个股 Market Context 时的目标输出。当前尚未证明跨日期报价预测能力；不能宣称为正式 dealer quote。
MARKET CONTEXT同 carry 反解为 offer-equivalent IV，作为二层监督标签、曲面形状校验和单日横截面验收。训练／验证和参考对比需要；日常独立推理不应读取原价。不能拆出纯商业加点，也不能让单日参考答案替代长期模型验证。
一句话：Realized 提供“过去和 P 测度的条件信息”；Market Context 提供“当天 Q/报价层的监督答案”；Model Estimate 学习怎样从前者走向后者。当前只有一个 Market Context 日期，所以二层已完成单日横截面校准，但还没有足够多日期来学习报价方随市场状态变化的动态规则。

模型训练和验证边界

第一层

1,648,061 行训练数据，5,531 个股票；目标为未来 1–4M realized。上市风险中性特征不直接进入第一层。

第二层

113,456 行训练、26,992 行留出；按报价向量分组，避免同一模板的 42 个节点泄漏到两边。

单日留组诊断

基准价格 MAE 164.64 bp；P→Q 桥 169.30 bp；二层调整后 62.80 bp；IV MAE 约 4.08 vol 点。

如何理解这些数字：它们是 2026-08-13 横截面留组结果，说明模型能复现这一日的报价形状；不是未来交易日预测准确率，也不是对冲表现。需要更多日期的个股报价或其他报价方，才能检验时间外稳定性。
